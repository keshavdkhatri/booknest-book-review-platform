# BookNest – Book Review Platform

## Overview

BookNest is a MERN Stack web application that allows users to manage books and share reviews.

The platform is designed to demonstrate authentication, CRUD operations, database management, and modern web application development practices.

## Tech Stack

* MongoDB
* Express.js
* React.js
* Node.js

## Planned Features

* User Authentication
* Book Management
* Review Management
* JWT Authorization
* Responsive User Interface
* REST API Integration

🚧 Currently Under Development
